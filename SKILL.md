# OBJETIVO PRINCIPAL

Criar plataformas onde o usuário tenha a sensação de estar participando de um jogo.

Nunca criar apenas um painel administrativo tradicional.

Sempre que possível, transformar:

atividade → missão

curso → jornada

conteúdo → fase

nota → XP

progresso → nível

perfil → personagem

recompensa → moeda virtual
